# Yogisaitech React Website

A responsive bilingual (English/Tamil) company website starter built with React, Vite, Tailwind CSS v4, Framer Motion and Lucide icons.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Included in this starter
- Responsive split-layout homepage
- YTS / Yogisaitech brand treatment
- English and Tamil language toggle
- Technology and creative studio service sections
- Portfolio category filters
- About, process, CTA and contact sections
- Contact form that opens a prefilled WhatsApp message
- Floating WhatsApp contact button
- Google Maps search link

## Before publishing
1. Replace sample portfolio images and titles with real Yogisaitech projects.
2. Replace or verify all imagery and ensure you have rights to use it.
3. Verify the business address and phone number.
4. Configure a real form/email backend if you want enquiries sent without WhatsApp.
5. Add your final logo artwork and favicon.
6. Test on actual mobile devices and deploy the `dist/` build.

## Notes
- This is the initial homepage implementation, not the complete five-page website yet.
- Navigation currently scrolls to sections on the homepage. Dedicated About, Services, Portfolio and Contact routes can be added in the next phase.
- The language toggle translates the main homepage content; contact details remain the same in both languages.
